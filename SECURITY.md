# Security

This tool moves and renames files in a real Google Drive. A bug in the exclusion guard, the
validator or the executor is a security issue, not only a correctness issue.

Please report suspected problems privately through GitHub's "Report a vulnerability"
(Security tab > Advisories) rather than a public issue. Include the smallest manifest or tree
that reproduces it, with any personal names replaced.

Do not paste real indexes, reports, quarantine files or journals into issues: they contain
your file names.
